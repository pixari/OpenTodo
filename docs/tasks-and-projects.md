# Tasks and projects

<picture><source srcset="images/project-list-dark.webp" media="(prefers-color-scheme: dark)"><img src="images/project-list-light.webp" alt="The Home renovation project with its tasks grouped under the sections Planning and In progress."></picture>

A task is one thing to do. A project is a list of tasks that belong together. Each section below links to its full guide.

## Add a task

Press <kbd>q</kbd> anywhere in a task list, type, and press <kbd>Enter</kbd>. One line can also set the date, project, label, priority and estimate:

```
Order new taps friday #Home @errand p2 +20m
```

New tasks without a project land in the **Inbox**. See [Work from the list](work-from-the-list.md#add-a-task) and the [quick add reference](quick-add.md).

## Edit a task

Click a title (or press <kbd>F2</kbd>) to edit it in place; click the rest of the row, or press <kbd>Enter</kbd>, to open its panel. Press <kbd>→</kbd> to [expand the row](expand-a-row.md) instead. Changes save as you make them. See [The task panel](task-panel.md) and [Notes, subtasks and dependencies](notes-and-subtasks.md).

### Quick changes from the list

Select a task and press a key: <kbd>c</kbd> completes it, <kbd>1</kbd> to <kbd>4</kbd> set the priority, <kbd>L</kbd> adds labels. The full table is in [Work from the list](work-from-the-list.md#quick-changes-from-the-list).

### Dates and times

A due date is a calendar day; a time is the clock time where you are. Type them in words like `tomorrow` or `3pm`, pick them from a calendar, or fix a time to a time zone. See [Dates and times](dates-and-times.md).

### Deadlines

A deadline is the day a task must be finished by, separate from the day you plan to work on it; the task's row shows a countdown. See [Deadlines and start dates](deadlines-and-start-dates.md#deadlines).

### When a task starts

**Start** defers a task until a date or parks it in Someday, and **This Evening** puts a task due today in its own group. See [Deadlines and start dates](deadlines-and-start-dates.md#when-a-task-starts).

### Wait for another task

**Blocked by** makes a task wait for other tasks: it is dimmed with a lock until they are done. See [Notes, subtasks and dependencies](notes-and-subtasks.md#wait-for-another-task).

## Change several tasks at once

Tick tasks with <kbd>x</kbd> or their checkboxes, then **Actions** (or <kbd>.</kbd>) changes all of them in one go, with **Undo** afterwards. See [Change several tasks at once](bulk-actions.md).

## Complete, reopen and delete

Click the circle next to a task, or press <kbd>c</kbd>; reopen it from **Completed** in the sidebar. Deleting a task moves it and its subtasks to the Trash. See [Work from the list](work-from-the-list.md#complete-reopen-and-delete) and [Trash and history](trash-and-history.md).

## Break a task into subtasks

Open the task and type in **Add subtask**, or select it in the list and press <kbd>a</kbd>. Subtasks appear indented under their parent, which shows your progress, like **1/3**. See [Notes, subtasks and dependencies](notes-and-subtasks.md#break-a-task-into-subtasks).

## Organise with projects

Create a project with **+** next to **Projects** in the sidebar; pick a parent to make it a sub-project. The **Project** menu colours, moves, renames, duplicates, archives or deletes it. See [Projects and sub-projects](projects.md) and [Sections and boards](sections-and-boards.md).

## Project notes

Every project can carry a note above its tasks; <kbd>Shift</kbd>+<kbd>P</kbd> edits it. See [Project notes](project-notes.md).

## Put things in order

In the Inbox and in projects, you decide the order: drag a task, or select it and press <kbd>Alt</kbd>+<kbd>↑</kbd> / <kbd>Alt</kbd>+<kbd>↓</kbd>. See [Work from the list](work-from-the-list.md#put-things-in-order).

## Tips

- Keep the Inbox as a landing spot: capture fast, then sort into projects once a day.
- Use priorities sparingly. If everything is P1, nothing is.
- A task with an estimate shows it on the row, like `30m`, which makes it easy to spot quick wins. The **Filter** action in a list's header can show only tasks of 15 minutes or less (**Quick wins**).
