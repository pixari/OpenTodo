# Keyboard shortcuts

<picture><source srcset="images/shortcuts-dark.webp" media="(prefers-color-scheme: dark)"><img src="images/shortcuts-light.webp" alt="The Keyboard shortcuts dialog open over the Today view."></picture>

Everything in OpenTodo can be done from the keyboard. You don't need to learn it all: <kbd>q</kbd> to add, <kbd>j</kbd> / <kbd>k</kbd> to move, <kbd>c</kbd> to complete and <kbd>?</kbd> to look up the rest gets you a long way.

Shortcuts don't fire while you're typing in a field. Press <kbd>Esc</kbd> to leave the field first.

A key does one thing at a time: the shortcuts of where you are (the task panel, a board, the calendar, a list) win over the ones that work everywhere, so <kbd>1</kbd> sets the priority of the open task while the panel has focus and of the selected row otherwise. Every action's key is shown in its tooltip and next to its menu item; to see the keys printed in the app itself too, turn on **Settings → General → Keyboard → Show shortcut hints** on that device.

## See them in the app

Press <kbd>?</kbd> at any time for the cheat sheet. The shortcuts for where you are come first (the list, the board, the calendar, the task panel), then the ones that work everywhere and the **Go to** keys, and a search box at the top finds a shortcut by key or by what it does. Each line shows what a shortcut does and its keys; hover it for the full description. It's the same list as on this page, generated from the same source, so the two always match.

## The ones to learn first

| Keys | Does |
| --- | --- |
| <kbd>q</kbd> | Add a task |
| <kbd>j</kbd> / <kbd>k</kbd> | Move down and up the list |
| <kbd>Enter</kbd> | Open the selected task |
| <kbd>c</kbd> | Complete it |
| <kbd>1</kbd> … <kbd>4</kbd> | Set its priority |
| <kbd>g</kbd> then <kbd>t</kbd> | Go to Today (<kbd>i</kbd> for Inbox, <kbd>u</kbd> for Upcoming) |
| <kbd>Esc</kbd> | Close the panel |

A two-step shortcut like <kbd>g</kbd> then <kbd>t</kbd> means: press <kbd>g</kbd>, let go, then press <kbd>t</kbd>. Pause after <kbd>g</kbd> and a card in the middle of the screen waits for the second key and lists every key that can follow; press or click one, or press <kbd>Esc</kbd> to cancel.

With a screen reader, <kbd>j</kbd> / <kbd>k</kbd> move focus to the selected row, so it reads the task with its dates, counts and notes; subtasks are read with their level. Going to another page moves focus to the page's heading and the browser tab names the page. The first <kbd>Tab</kbd> on a page reaches **Skip to content**, which jumps past the sidebar.

On a Mac, use <kbd>⌘</kbd> where this page says <kbd>Ctrl</kbd>, and <kbd>Option</kbd> for <kbd>Alt</kbd>.

## Vim keybindings

If you're used to Vim, turn on **Settings → General → Keyboard → Vim keybindings**. It's off by default and applies to that device only. With it on, a small indicator shows the mode (Normal, Insert or Command), and you get:

- counts like <kbd>3</kbd><kbd>j</kbd>, <kbd>g</kbd><kbd>g</kbd> and <kbd>G</kbd> for the first and last task,
- <kbd>d</kbd><kbd>d</kbd> to delete, <kbd>x</kbd> to complete, <kbd>o</kbd> to add a task below and <kbd>i</kbd> to edit,
- <kbd>J</kbd> / <kbd>K</kbd> to move the selected task,
- a command line on <kbd>:</kbd> with `:today`, `:project <name>`, `:new <title>`, `:sync` and `:help`.

All the usual shortcuts keep working. With Vim keybindings on, the <kbd>?</kbd> list includes a Vim section.
